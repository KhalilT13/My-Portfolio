# Khalil Talhami — Personal Portfolio

A personal portfolio website built to showcase my projects, skills, education, and contact information as a Software Engineering student.

## Overview

This portfolio presents my background, technical skills, and selected software projects in a clean and responsive layout. It is designed to be simple, modern, and easy to navigate for recruiters, lecturers, and anyone interested in my work.

## Features

* Responsive design for desktop and mobile screens
* Smooth scrolling navigation
* Hero section with personal introduction
* About section
* Skills section
* Projects section
* Contact section
* Resume download button
* Clean and modern UI

## Technologies Used

* HTML
* CSS
* JavaScript
